Feature Flags

Allow students to top up their wallets via Paystack.

Fare Settings

⚠️ These are display values only. Update the constants in student.js and rider.js to change actual charges.

Road / Path Closures

Mark a campus road or path as temporarily closed. The app will avoid it in routing. Geometry is managed in QGIS — this only sets operational overrides.

Ride Stops

Ride stops come from the bundled map data (QGIS export). To add or move a stop, update the QGIS project and re-export.
